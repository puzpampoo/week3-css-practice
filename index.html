Welcome to my practice website

This website contains my solutions to 15 CSS Basics exercises. Each page explains one CSS idea, shows a live example, and includes the code used to make it.

Beginner (5 exercises)

Exercise 1: Text Styling

Style a paragraph with blue text, an 18px font size, and Arial.

Exercise 2: Class Selector

Use a .highlight class to give selected words a yellow background.

Exercise 3: Box Model Basics

Show width, padding, border, and margin on a div.

Exercise 4: Colors

Apply HEX, RGB, and HSL colors to three separate text lines.

Exercise 5: Link Hover Effect

Make a navigation link turn red when a visitor hovers over it.

Intermediate (5 exercises)

Exercise 6: Positioning

Exercise 7: Profile Card

Create a centered profile card with rounded corners and a shadow.

Exercise 8: Flexbox Navigation

Use Flexbox to arrange menu items in a horizontal row with equal spacing.

Exercise 9: Grid Layout

Build a two-column layout with a 30% sidebar and 70% main content.

Exercise 10: Media Queries

Reduce heading sizes on screens narrower than 600px.

Challenging (5 exercises)

Exercise 11: Flexbox Gallery

Create a responsive image gallery with four columns on wide screens and two on small screens.

Exercise 12: Sticky Header

Use position: sticky to keep a header near the top while scrolling.

Exercise 13: Animated Button

Add a smooth hover transition to a button.

Exercise 14: Grid-based Landing Page

Use CSS Grid to place a header, sidebar, main content, and footer.

Exercise 15: Responsive Card Layout

Display cards in a row on desktop and stack them on mobile.
