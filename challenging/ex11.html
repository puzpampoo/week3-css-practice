What this exercise demonstrates

Create a responsive image gallery with four columns on wide screens and two on small screens.

HTML code

<div class="ex11-gallery">
  <div class="gallery-tile">Photo 1</div>
  <div class="gallery-tile">Photo 2</div>
  <div class="gallery-tile">Photo 3</div>
  <div class="gallery-tile">Photo 4</div>
</div>

CSS used

.ex11-gallery { display: flex; flex-wrap: wrap; gap: 1rem; }
.gallery-tile { flex: 1 1 calc(25% - 1rem); }
@media (max-width: 600px) { .gallery-tile { flex-basis: calc(50% - 1rem); } }
