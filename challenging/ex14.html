HTML code

<div class="ex14-landing">
  <header>Header</header>
  <aside>Sidebar</aside>
  <main><h3>Main content</h3><p>A simple landing page layout made with CSS Grid.</p></main>
  <footer>Footer</footer>
</div>

CSS used

.ex14-landing { display: grid; grid-template-columns: 1fr 3fr; grid-template-areas: 'header header' 'sidebar main' 'footer footer'; gap: 1rem; }
.ex14-landing header { grid-area: header; }
.ex14-landing aside { grid-area: sidebar; }
.ex14-landing main { grid-area: main; }
.ex14-landing footer { grid-area: footer; }
